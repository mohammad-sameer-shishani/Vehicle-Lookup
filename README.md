# vehicle-lookup

## Setup Instructions

1. Clone the repository:
   ```bash
   git clone https://github.com/mohammad-sameer-shishani/Vehicle-Lookup.git
   ```
2. Navigate to the api directory:
   ```bash
   cd vehicle-lookup-api
   ```
3. Install dependencies:
   ```bash
   dotnet watch
   ```
   (make sure dotnet installed)
4. Navigate to the project directory:
   ```bash
   cd ..
   cd vehicle-lookup-ui
   ```
5. Install dependencies:
   ```bash
   npm install
   ```
   (make sure angular cli in installed)

## Usage

1. Start the application:
   ```bash
   npm start
   ```
2. Open your browser and navigate to:
   ```
   http://localhost:4200
   ```

3. Use the interface to look up vehicle information.
